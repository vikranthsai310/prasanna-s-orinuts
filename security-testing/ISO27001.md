### 1. 🔴 CRITICAL: Sensitive File in Documentation
**File:** Multiple documentation files reference:
```
orinut-494cc-firebase-adminsdk-fbsvc-7b087e3184.json
```

**Risk:** If this service account JSON is committed to Git, it contains:
- Firebase project credentials
- Admin-level access keys
- Private keys

**Immediate Actions Required:**
```bash
# 1. Check if file exists in Git history
git log --all --full-history -- "*firebase-adminsdk*.json"

# 2. If found, remove from history
git filter-branch --force --index-filter \
  "git rm --cached --ignore-unmatch *.json" \
  --prune-empty --tag-name-filter cat -- --all

# 3. Force push (DANGEROUS - coordinate with team)
git push origin --force --all

# 4. Revoke and regenerate service account
# Go to Firebase Console → Project Settings → Service Accounts
# Delete compromised service account
# Create new service account
# Update environment variables
```

**Priority:** 🔴 CRITICAL - Act within 24 hours

### 2. 🔴 CRITICAL: Hardcoded Admin Credentials
**Location:** `firestore.rules`, `firestore-secure.rules`

```javascript
// VULNERABLE CODE
function isAdmin() {
  return request.auth != null &&
    request.auth.token.phone_number in ['+918555856366', '+916301308477'];
}
```

**Risks:**
- Admin numbers exposed in public repository
- Cannot easily revoke admin access
- No audit trail of admin actions
- Difficult to manage multiple admins

**Solution:**
```javascript
// SECURE APPROACH
function isAdmin() {
  return request.auth != null &&
    exists(/databases/$(database)/documents/admins/$(request.auth.uid));
}

// Firestore structure
admins (collection)
  └─ {userId} (document)
      ├─ email: "admin@example.com"
      ├─ role: "super_admin"
      ├─ grantedAt: timestamp
      └─ grantedBy: "system"
```

**Migration Steps:**
1. Create `admins` collection in Firestore
2. Add admin user documents
3. Update security rules
4. Test thoroughly
5. Deploy

**Priority:** 🔴 CRITICAL

---

### 3. 🟡 HIGH: Missing Rate Limiting
**Location:** Authentication endpoints, API calls

**Risk:** Brute force attacks, DoS attacks

**Solution:**
```typescript
// Implement rate limiting
import rateLimit from 'express-rate-limit';

const authLimiter = rateLimit({
  windowMs: 15 * 60 * 1000, // 15 minutes
  max: 5, // limit each IP to 5 requests per windowMs
  message: 'Too many authentication attempts, please try again later'
});

app.post('/api/auth/login', authLimiter, loginHandler);
```

---

### 4. 🟡 HIGH: Insufficient Input Validation
**Location:** Multiple API endpoints

**Found:**
```typescript
// Minimal validation
const { amount, currency } = req.body;
// Missing: type checking, range validation, sanitization
```

**Solution:**
```typescript
import Joi from 'joi';

const orderSchema = Joi.object({
  amount: Joi.number().positive().max(1000000).required(),
  currency: Joi.string().valid('INR').required(),
  items: Joi.array().items(
    Joi.object({
      id: Joi.string().required(),
      quantity: Joi.number().integer().positive().max(100).required()
    })
  ).min(1).required()
});

// Validate before processing
const { error, value } = orderSchema.validate(req.body);
if (error) {
  return res.status(400).json({ error: error.details[0].message });
}
```
